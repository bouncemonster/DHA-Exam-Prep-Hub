# DHA Exam Prep Hub

Interactive browser platform for Dubai Health Authority medical licensing exam preparation.

- Full exam simulator (timer + scoring)
- Local-only storage in the browser (no backend required)
- Guidelines, time-management notes, and weak-area tracking

Open `index.html` in a modern browser, or use the GitHub Pages site if enabled on this repo.

This README is an agent-safe stub so the repository is discoverable; it does not invent features beyond the shipped static app.
